# 🌍 تمدن زمین (Civ-Earth)

بازی استراتژیک نوبتی **چندنفره‌ی آنلاین** روی نقشه‌ی واقعی کره‌ی زمین.
قوم خود را در هر نقطه از زمین بنیان بگذار، دهکده را به شهرستان برسان، فناوری بیاموز، لشکر بباف و جهان را فتح کن.

## ✨ امکانات

- **نقشه‌ی واقعی زمین**: حدود ۱۷۵۰ منطقه‌ی واقعی از داده‌های Natural Earth با اقلیم (دشت، جنگل، جنگل استوایی، بیابان، تندرا، تیگاه، کوهستان)، ساحل و رودهای واقعی (نیل، دجله، آمودریا و…)
- **قومیت‌ها**: ۶ قوم با ویژگی‌های متفاوت (ایرانی‌تبار +۲۵٪ علم، جنگ‌جو، کوچ‌نشین، دریانورد، کوه‌نشین، کشاورز)
- **رشد شهر**: دهکده ← آبادی ← شهر ← شهرستان؛ جمعیت، غذا، تولید، طلا و علم
- **درخت فناوری**: ۲۶ فناوری در ۴ شاخه (رشد، نظامی، دانش، فرهنگ)
- **جنگ**: ۶ نوع واحد از شهاب‌سنگ تا منجنیق، دفاع زمین، بارو، تصرف منطقه
- **چندنفره**: اتاق با کد ۵ حرفی، ۲ تا ۸ بازیکن + تا ۵ حریف AI، چت درون‌بازی
- **سبک**: بدون فریم‌ورک؛ کلاینت Canvas خالص (~۴۰KB کد)، سرور Node با یک وابستگی (`ws`)

## 🎮 راهنمای بازی

1. **لابی**: نام قوم و قومیت را انتخاب کن؛ «اتاق جدید» بزن یا با کد اتاق به دوستانت بپیوند.
2. **بنیان‌گذاری**: روی هر نقطه از نقشه کلیک کن و نخستین دهکده را بنا کن (کنار رود و ساحل = رشد بهتر).
3. **هر نوبت**: ساخت‌وساز، سربازگیری، پژوهش، گسترش قلمرو (ادعای منطقه‌های همسایه)، حرکت و حمله.
4. **پایان نوبت**: وقتی همه تمام کردند، نوبت پردازش می‌شود (نوبت‌های هم‌زمان).
5. **پیروزی**: تسلط بر ۴۰٪ خشکی‌های زمین، یا بالاترین امتیاز پس از ۲۰۰ نوبت.

## 🚀 اجرا

```bash
npm install
npm start          # روی http://localhost:3000
```

سپس مرورگر را باز کن. دوستانت با `http://IP-سرور:3000` و کد اتاق وارد می‌شوند.

## ☁️ آنلاین‌کردن (استقرار)

سرور فقط به Node.js نیاز دارد (پورت دلخواه با متغیر محیطی `PORT`):

```bash
PORT=80 node server/server.js
```

گزینه‌های ساده:
- **VPS ارزان** (مثلاً ۲ گیگ رم): `npm install && pm2 start server/server.js` — سپس Nginx به‌عنوان reverse-proxy برای WebSocket (`proxy_set_header Upgrade $http_upgrade;`).
- **Render / Railway / Fly.io**: ریپو را وصل کن؛ دستور شروع `npm start` و پورت از `process.env.PORT` خوانده می‌شود. برای WebSocket نیازی به تنظیم اضافه نیست.

> توجه: برای HTTPS (لازم برای WSS در دامنه‌های واقعی) از Cloudflare یا Nginx + Certbot استفاده کن؛ کلاینت خودکار `ws`/`wss` را تشخیص می‌دهد.

## 🗺 بازسازی نقشه (اختیاری)

نقشه از داده‌های آماده ساخته شده و نیازی به بازسازی نیست، اما اگر خواستی:

```bash
node tools/build-map.js   # خروجی: client/data/map.json
node tools/preview.js     # پیش‌نمایش PNG در tools/preview.png
```

داده‌های منبع در `tools/geo/` (Natural Earth 110m: خشکی، دریاچه‌ها، رودها — public domain).

## 🧪 تست

```bash
npm test   # تست دود قوانین: بنیان‌گذاری، ادعا، حرکت، نبرد، ۴۰ نوبت AI
```

## 📁 ساختار

```
server/server.js    سرور WebSocket + میزبانی استاتیک (اتاق‌ها، نوبت‌ها، AI)
shared/rules.js     قوانین مشترک بازی (سرور + مرورگر)
shared/ai.js        هوش مصنوعی حریف‌ها
client/             کلاینت (Canvas، رابط فارسی، لابی)
tools/              ساخت نقشه، پیش‌نمایش، تست
```
